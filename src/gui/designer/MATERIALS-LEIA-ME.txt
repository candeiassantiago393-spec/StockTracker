Stock Tracker - Materials no Qt Designer
========================================

Ficheiro principal:  gui_materials.ui
Abrir:               DESIGNER.bat  ->  opcao 2

Layout (igual a Components, template Siemens):
  Coluna esquerda - Operations
    - Search Material  + SEARCH
    - Scan Barcode / Supplier Ref.  + Copy
  Coluna direita - Material Details
    - Supplier Reference, Serial Number, Description
    - Calibration Date, Calibration Expiration  (+ Copy cada um)

Metricas partilhadas (nao alterar sem atualizar styles.py):
  Margens pagina: 16 px esquerda/direita
  Etiquetas: 74 px | Campos: 100 px | Copy: 60 px | SEARCH: 124 px

Depois de editar no Designer
----------------------------
1. Copiar gui_materials.ui para:
     Downloads\StockTracker\StockTracker\src\gui\designer\
2. No projeto:
     tools\export-ui.bat
     python -m src.main

Regenerar a partir do codigo (so se mudou generate_materials_ui.py):
     python tools\generate_materials_ui.py

Atualizar esta pasta (repo + Ambiente de Trabalho):
     ORGANIZAR-DESKTOP.bat   (na raiz do projeto)

Popups Materials (reutilizam templates existentes):
  - Pesquisa:   popups\gui_popup_search.ui
  - Historico:  popups\gui_popup_history.ui
  - Add/Edit:   material_dialog.py (Python; popup dedicado em breve)

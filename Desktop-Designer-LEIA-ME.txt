Stock Tracker - Qt Designer
===========================

Desktop package used to edit the UI.

Files:
  gui_stocktracker.ui     - main window
  popups\                 - Siemens popups (manual, history, search)
  siemens_template\       - resources (logos, icons, gui_popup.ui)

Open:
  Double-click DESIGNER.bat (menu 1-4)

Refresh from the project (Downloads):
  cd Downloads\StockTracker\StockTracker
  .\tools\prepare-designer-desktop.ps1

After editing .ui files in Designer, back in the main project:
  .\tools\export_stocktracker_ui.ps1
  python -m src.main

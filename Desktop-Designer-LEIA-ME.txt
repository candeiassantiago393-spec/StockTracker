Stock Tracker - Qt Designer
===========================

Pacote para editar a interface no Qt Designer.

Ficheiros:
  gui_stocktracker.ui     - pagina Components     (DESIGNER.bat opcao 1)
  gui_materials.ui        - pagina Materials      (DESIGNER.bat opcao 2)
  MATERIALS-LEIA-ME.txt   - guia rapido Materials
  popups\components\      - popups Components (manual, edit, pesquisa, historico)
  popups\materials\       - popups Materials (material, pesquisa, historico)
  popups\shared\          - confirmacao + template Siemens
  siemens_template\       - recursos (logos, icones, templates)

Abrir:
  Duplo-clique em DESIGNER.bat (opcoes 1-8)

Atualizar a partir do projeto:
  cd Downloads\StockTracker\StockTracker
  tools\ORGANIZAR-DESKTOP.bat

Depois de editar .ui no Designer, no projeto principal:
  tools\export-ui.bat
  python -m src.main

Metricas alinhadas com template Siemens: ver src\gui\styles.py e tools\gui_ui_builder.py

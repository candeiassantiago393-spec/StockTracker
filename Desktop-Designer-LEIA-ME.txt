Stock Tracker - Qt Designer
===========================

Pacote para editar a interface no Qt Designer.

Ficheiros:
  gui_stocktracker.ui     - pagina Components
  gui_materials.ui        - pagina Materials
  popups\                 - popups Siemens (manual, historico, pesquisa, ...)
  siemens_template\       - recursos (logos, icones, templates)

Abrir:
  Duplo-clique em DESIGNER.bat (opcoes 1-8)

Atualizar a partir do projeto:
  cd Downloads\StockTracker\StockTracker
  powershell -File tools\sync_designer_package.ps1 -Target Desktop

Depois de editar .ui no Designer, no projeto principal:
  tools\export-ui.bat
  python -m src.main

Metricas alinhadas com template Siemens: ver src\gui\styles.py e tools\gui_ui_builder.py

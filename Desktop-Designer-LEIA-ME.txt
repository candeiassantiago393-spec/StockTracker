Stock Tracker — Qt Designer
===========================

Pasta no Ambiente de Trabalho para editar a interface (tutor / visual).

Ficheiros:
  gui_stocktracker.ui     — janela principal
  popups\                 — popups Siemens (manual, historico, pesquisa)
  siemens_template\       — recursos (logos, icones, gui_popup.ui)

Abrir:
  Duplo clique em DESIGNER.bat  (menu 1–4)

Atualizar a partir do projeto (Downloads):
  cd Downloads\StockTracker\StockTracker
  .\tools\prepare-designer-desktop.ps1

Depois de editar .ui no Designer, no projeto principal:
  .\tools\export_stocktracker_ui.ps1
  python -m src.main
